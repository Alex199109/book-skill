# Chapter 11: 尊重他人意见，切勿指责错误 (Show Respect for the Other Person's Opinions; Never Say "You're Wrong")

## Core Idea
永远不要直率地指责对方犯了错误，这等同于当面羞辱对方的智力、判断与自尊；用谦逊的探索姿态代替专断的宣判，才能引导对方自行纠偏。

## Frameworks Introduced
- **富兰克林去专断语言法 (Franklin's De-Dogmatization Technique)**:
  - When to use: 发现对方出现事实性错误、违规或逻辑漏洞时。
  - How:
    1. 彻底剔除武断断言：从个人词汇库中永久删除“显然”、“毫无疑问”、“绝对是这样”等带有绝对裁决意味的词汇。
    2. 替换为推测与主观感受词：“依我推断……”、“我揣测……”、“我当时是这样理解的，但现在情况或许有所不同”。
    3. 预设自我容错框架：开场使用经典缓冲句：“好吧，让我们来探讨一下……不过我可能有另外一种看法，而且我也经常把事情弄错；如果我错了，我很愿意改正过来。让我们看看究竟是怎么回事。”
    4. 邀请共同核验：将纠错转化为平等的科学探索，保留对方自尊。

## Key Concepts
- **苏格拉底认知觉悟 (Socratic Epistemic Humility)**: 智者苏格拉底常言：“我唯一知道的，就是我什么都不知道。”如果你不能保证自己每天75%的时间都是对的，凭什么断言别人是错的？
- **自尊依附偏见 (Ego Attachment to Prejudices)**: 鲁宾逊教授指出：我们在毫无阻力时会自然改变意念，但一旦有人指出我们的过失，我们会瞬间变得极其固执与狂怒，因为这伤害了我们的自尊心。
- **外交手腕法则 (Diplomatic Finesse)**: 公元前两千两百年埃及法老训诫王子：“善用外交手腕，方能助你达成所愿。”

## Mental Models
- **Think of Direct Contradiction as a Physical Blow**: 当面指出别人错了，如同在他人面门挥出一记重拳，只会激发对方反击的本能，绝不会带来妥协。
- **Use the Scientific Inquiry Stance**: 像北极探险家史蒂文生一样——“科学家从不敢急于求证什么，我们只是试着去探寻事实。”

## Anti-patterns
- **法庭审判官姿态 (The Judgemental Inquisitor)**: 年轻律师在最高法院法官面前当场指出“法官阁下，海军法中根本没有这项时效条款”，导致满堂气温骤降至零度，彻底失去胜诉可能。
- **当众戳破与自夸高明 (Exposing Others to Flaunt Superiority)**: 抢着展示证据证明“你看，我早就说你搞错了”，将同仁或客户推向无地自容的绝境。

## Worked Example
纽约泰洛木材厂推销员克劳雷过去常常在木材分级问题上与买方检查员争执得面红耳赤，导致公司损失惨重。后来某大客户电话通知其工厂木材完全不合格并停止卸货，声称55%的木料低于等级要求。克劳雷赶到现场后，并未搬出规则手册跟检查员辩论，而是以极度友好谦逊的态度请求：“请继续卸货，并请把您认为不合格的木料单独挑出来，让我看看我们究竟做错了什么，以便日后改进。”在验货过程中，克劳雷仔细观察，发现检查员熟悉硬木标准，但对眼前的白松木规则并不内行。克劳雷绝口不指责对方不懂行，而是不断赞赏检查员工作细致、把关严谨，随后温和地请教几个技术细节，含蓄地让对方意识到这批木材其实完全符合白松木的标准。检查员态度逐渐彻底软化，主动向克劳雷坦白自己对白松木经验不足，最终重新检查全车木料并全数签收，当场开出货款支票。克劳雷用外交手腕为公司挽回了损失，更赢得了客户长久的信任。

## Key Takeaways
1. 告诉一个人他错了，无论用眼神、声调还是手势，都如同言语一样具有摧毁性。
2. 即使你拥有绝对的事实与逻辑，用尖锐的方式指出他人的过失，除了树立敌人外毫无益处。
3. 允许他人保留犯错的台阶，人们在受到尊重的情况下，往往会主动承认自己的疏漏。
4. 查斯特菲尔德勋爵训子格言：“我们要比别人聪明，但绝不要告诉别人你比他聪明。”
