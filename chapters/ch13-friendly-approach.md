# Chapter 13: 以友善的方法开始 (Begin in a Friendly Way)

## Core Idea
“一滴蜂蜜比一加仑胆汁能捕获更多的苍蝇”；若想说服他人接纳你的意志，必须首先让对方确信你是其真诚的朋友，温和与友善的力量永远凌驾于愤怒与暴力之上。

## Frameworks Introduced
- **阳光融雪沟通法则 (The Sunshine Warmth Persuasion Protocol)**:
  - When to use: 面对心存戒备、劳资对立、邻里纠纷或谈判僵局时。
  - How:
    1. 卸下对抗武装：摒弃最后通牒、威胁或强力高压手段（如同伊索寓言中北风猛吹只会让旅人把大衣裹得更紧，而太阳的温和照耀能让旅人主动脱下大衣）。
    2. 建立情感共情纽带：开场坦承双方的共同利益、彼此家庭的福祉以及合作的诚意。
    3. 给予超出预期的关怀：在对峙期施加友善行为（如罢工期间厂长为工人购买棒球用具、提供活动场地）。
    4. 用征询与探讨代替宣判：使用和缓词汇引导对方走向理智大路。

## Key Concepts
- **林肯蜂蜜格言 (Lincoln's Honey Axiom)**: “一滴蜂蜜比一加仑胆汁能捕获更多的苍蝇。如果你要赢得一个人赞同你的见解，先让他相信你是他忠实的朋友，这便是一滴黏住他心扉的蜂蜜。”
- **无公害沟通语言 (Webster's Gentle Litotes)**: 传奇律师丹尼尔·韦伯斯特的名言：“这情形似乎有探索的必要……”、“我相信诸位绝不会忽略这项事实……”用最温和的措辞陈述最无可辩驳的理由。

## Mental Models
- **Think of Cold Conflict as Ice**: 铁锤砸冰块会碎屑四溅甚至反伤自身，唯有温暖的阳光能将坚冰无声化为清泉。
- **Use the Strike Clean-Up Metaphor**: 当管理者展现真正的友善与体恤时，正在要求加薪的罢工工人甚至会主动拿起扫帚自发打扫厂区环境。

## Worked Example
1915年科罗拉多州爆发了美国工业史上最惨烈的工潮，洛克菲勒控股的煤铁公司矿工因加薪诉求引发长达两年的流血冲突，厂房被毁、军队镇压、死伤惨重，全州矿工对洛克菲勒恨之入骨，甚至有人扬言要将其吊死。在仇恨阴云笼罩全城之际，年轻的约翰·D·洛克菲勒亲赴矿区数周，走访工人家庭，与矿工遗孀、孩子交谈。随后，他面对怒火中烧的工人代表发表了一场名垂青史的演说。洛克菲勒开场极其和蔼谦卑：“这是我一生中最值得纪念的一天……前些日子我有机会去探访各位的住所，与代表们促膝长谈，见到了你们的太太和孩子。今天我们在这里见面，我们不再是陌生人，而是彼此拥有共同利益的朋友……虽然我不是公司的管理人员或劳工代表，但作为股东代表，我深深感激大家……”在这场温和、真诚的演讲后，罢工矿工的暴戾情绪彻底平息，无一人再提加薪激化矛盾，所有人自愿复工，双方结成紧密的合作纽带。

## Key Takeaways
1. 房客司托伯面对刻板顽固的房东，没有搬出法条退租争吵，而是进门极力赞美公寓的维护与房东的管理手腕，房东受宠若惊，主动为他下调房租。
2. 长岛名媛戴夫人的家宴因管家爱弥尔调度失职而办得一团糟；戴夫人次日没有痛骂，反而赞美其平日的卓越管理并宽慰其“菜品非你亲手所做，不必自责”，管家感动之余在下一场宴会中献上了王室级别的顶级服务。
3. 盛怒之下的拳头只会引来对方握得更紧的拳头；围坐商议、求同存异才能开启理智之门。
4. 报社刊登虚假医药广告，波士顿B医生没有发动教会抵制，而是写信由衷赞美报纸的社论品质并表达父母对广告污染纯洁女儿的遗憾，报社发行人感激之余主动全面撤销下架不良广告。
