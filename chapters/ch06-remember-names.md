# Chapter 6: 记住每一个人的姓名 (Remember that a Person's Name is Sweetest Sound)

## Core Idea
对任何人而言，自己的名字是所有语言中最甜蜜、最重要的声音；记住并准确叫出他人的名字，是给予对方无声却极其强烈的赞赏与重视，而忘记或拼错名字则是严重的冒犯。

## Frameworks Introduced
- **吉姆·法利姓名记忆系统 (Jim Farley's Name Retention System)**:
  - When to use: 结识新客户、选民、合作伙伴或下属员工。
  - How:
    1. 初见捕捉确认：初次听闻名字时，若未听清立即要求对方重复或询问拼写（“对不起，请问这个字怎么拼写？”）。
    2. 脑内关联强化：交谈期间，在心中将对方的姓名、相貌特征、神态举止以及家庭背景进行多次联结刻画。
    3. 纸笔私下记录：独处时立即将该人姓名、职业、家眷人口、特殊爱好写在记事簿上，加深视觉与神经印记。
    4. 随时间复习调用：下次见面时，准确叫出其全名，并主动垂询其家事细节（如后院花草、子女升学）。

## Key Concepts
- **姓名中心性 (Name Primacy Bias)**: 人类对自己名字的重视程度，胜过世界上其他所有名字的总和；名字是个人身份认同与自尊的最直接载体。
- **卡耐基命名赋能法 (Carnegie Name-Honoring Strategy)**: 钢铁大王将商业合作、铁路供货及重要机构以关键决策者命名，满足对方留名青史的渴望，换取巨额商业订单。
- **微小牺牲铸就教养 (Courtesy Built on Small Sacrifices)**: 爱默生名言：“良好的礼貌，是由微小的牺牲所构成的。”花费心思与记忆力去牢记他人姓名，就是最昂贵的人格礼貌。

## Mental Models
- **Think of a Name as an Identity Anchor**: 准确叫出名字就像把船锚稳稳扎进对方的心坎；叫错名字如同在对方船体撞出一个窟窿。
- **Use the Carnegie Rabbit Trick**: 幼年卡耐基用邻家孩子的名字为初生幼兔命名，让孩子们心甘情愿漫山遍野为兔子采集饲料；成人亦是如此，给项目或设施冠以对方的名字，对方会视如己出。

## Worked Example
安德鲁·卡耐基幼年贫寒，但他早在苏格兰童年时期就洞悉了人性的这一密码。他养了一只母兔生下一窝兔崽，却缺少草料喂养。卡耐基把邻近的孩子们召集起来宣布：谁每天采摘蒲公英和苜蓿草喂养小兔，这只兔子就用谁的名字来命名。孩子们争先恐后奔赴田野采草，兔子养得极其肥壮。成年后经营巨额工业时，卡耐基再度重现该技巧：当他准备将钢轨卖给宾夕法尼亚铁路局时，他直接将自己在匹兹堡新建的超大钢铁厂命名为“埃德加·汤姆生钢铁厂”（汤姆生即该铁路局局长）。当铁路局采购钢轨时，汤姆生局长毫不犹豫地将巨额订单全部交给了冠有自己姓氏的工厂。同样，在争夺卧铺车厢业务时，卡耐基与对手布尔姆公司陷入毁灭性恶性削价竞争；卡耐基在饭店截住布尔姆，提出两家合并，并提议新公司命名为“布尔姆皇宫卧车公司”。布尔姆脸上的坚冰瞬时融化，立即邀请卡耐基到客房彻夜详谈，达成工业史上的伟大重组。

## Key Takeaways
1. 吉姆·法利未上过高中，却凭借能叫出五万人姓名的神奇记忆力，帮助罗斯福成功入主白宫并担任邮政总长。
2. 罗斯福总统在克莱斯勒为其特制残障汽车时，不仅能当面直呼设计师张伯伦的名字，更在临走前特意走到羞怯躲在角落的普通技工面前，握手叫出其姓名并诚挚道谢。
3. 拼错对方名字、念错音节或忘却姓名，会向对方潜意识释放“你在我眼中无足轻重”的致命信号。
4. 无论是国家元首、百货巨子还是街头车夫，将自己的名字镌刻在建筑物、轮船或书册上，是人类最古老而顽固的愿望。
