# Chapter 26: 顾全对方的面子 (Let the Other Person Save Face)

## Core Idea
肆意践踏他人的感情与尊严是人际交往中最残忍的暴行；在裁撤职位、指出疏漏或面临对抗时，花费几分钟换位思考、说一两句体恤温存的话，为对方留足体面与台阶，能化解无尽的仇恨。

## Frameworks Introduced
- **面子保全与尊严缓冲机制 (Face-Saving De-escalation Protocol)**:
  - When to use: 辞退解雇员工、降职调岗、公开指正错误或战胜竞争对手时。
  - How:
    1. 坚决避免公开羞辱：绝不在第三者面前、在下属或家人面前当众痛斥当事人的无能。
    2. 剥离能力与岗位匹配：若某人在当前岗位表现糟糕，将其定义为“专长错配”而非“智力缺陷”（如通用电气将不称职的会计部长调任为顾问工程师）。
    3. 给予隆重的名誉台阶：在解雇或职务变动时，先由衷赞扬其过往的突出贡献与独特才干，让其体面退场。
    4. 战胜对手后的骑士风度：胜利者绝不居高临下、不可一世，主动承担部分客观责任，将失败归因于竞技比赛的常态，抚平失败者的心头创痛。

## Key Concepts
- **尊严神圣不可侵犯 (Sanctity of Human Dignity)**: 法国作家圣埃克苏佩里名言：“我没有任何权利去说或做任何事情，来贬损一个人在自己眼中的形象。重要的不是我怎么看待他，而是他如何看待他自己；伤害一个人的自尊是一项极大的罪恶。”
- **凯末尔的胜者气度 (Mustafa Kemal's Chivalry)**: 土耳其国父凯末尔在击溃希腊侵略军并俘获其最高司令官时，不仅严禁民众侮辱降将，反而热情握手看座，温和宽慰：“胜败乃兵家常事，战争正如一场竞技，最高手有时也会失手。”

## Mental Models
- **Think of Face as a Person's Emotional Armor**: 剥夺一个人的面子就像在战场上扒光战士的盔甲，逼其赤身裸体，对方唯有与你决一死战。
- **Always Build a Golden Bridge for Retreat**: 孙子兵法“围师必阙”——给犯错者留一条体面的退路，避免困兽犹斗。

## Worked Example
著名电气工程泰斗斯坦米兹先生在电机科学领域拥有无与伦比的天才头脑，是通用电气不可多得的瑰宝。然而通用电气高层在任命其担任会计部部长后，发现斯坦米兹在财务管理方面一塌糊涂、简直等于废物，严重拖累了公司运营。但他性格极其敏感脆弱，高管们不敢轻易撤换他，生怕得罪并失去这位电气宗师。如果粗暴撤职，必将导致斯坦米兹愤然辞职并引发行业震荡。通用电气高层展示了高超的“保全面子”艺术：董事会没有对其财务管理上的灾难提出任何公开批评，而是专门增设了一个极具声望的全新高管头衔——“通用电气特聘咨询顾问工程师”，免去其繁重的会计琐事，恭请其专职指导公司全部重大电气技术攻关。斯坦米兹欣喜若狂，体面与自尊得到了无与伦比的彰显；而公司也顺畅指派了新的财务专家掌管会计部。一场原本可能引发灾难的重大人事危机，在平和友善的气氛中圆满解决。

## Key Takeaways
1. 会计师事务所合伙人格雷琪在每年旺季结束后辞退临时雇员时，逐个召见并详述其在复杂项目中展现的才干与勤勉，感激其付出并承诺下一季优先返聘，被辞退员工备受感动、心怀感激。
2. 即使我们百分之百正确，而对方百分之百错误，让对方丢尽脸面除了摧毁其自我价值外毫无益处。
3. 批评孩子或责备佣人时，当众呵斥会直接摧毁对方的自尊堡垒，永远私下温和沟通。
4. 改变他人而不引起反感的第五项法则：顾全对方的面子。
