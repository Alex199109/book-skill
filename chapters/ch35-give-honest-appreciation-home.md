# Chapter 35: 给予伴侣真诚的赞美与感激 (Give Honest Appreciation)

## Core Idea
很多男性以为给家里提供面包便尽到了天职，却长年忽略给予妻子自尊与美的滋养；由衷地赞美太太的厨艺、衣着、容颜与操持，是男人在婚姻中能付出的成本最低却收益最丰厚的投资。

## Frameworks Introduced
- **家庭日常赞赏赋能体系 (Domestic Appreciation Engine)**:
  - When to use: 每日用餐、伴侣换上新装、整理完家务或在工作生活中遭遇挫折时。
  - How:
    1. 绝不将付出视作理所当然：深知伴侣在灶台与家务前的繁琐劳作需要被看见与认可。
    2. 具体的厨艺赞美：当太太端上一道精心烹制的烤鸡时，绝不低头闷吃，大声赞叹其风味绝佳并具体夸奖酱汁与火候，让她知道你在品味佳肴而非吃草。
    3. 敏锐捕捉衣着修饰：留心伴侣新换的发型、甚至几年前穿过的别致裙装，给予诚挚动人的肯定。
    4. 表达对伴侣的敬佩与依赖：公开向外界与朋友宣称：“我今日取得的一切成就，全仰仗我太太的支持与智慧。”

## Key Concepts
- **女人“不吃草”公理 (The "Not Eating Hay" Parable)**: 农妇劳作二十年，在辛苦做完晚饭后给男工们面前倒下一大堆枯草；面对众人的愤怒质问，她回答：“这二十年来无论我做多美味的饭菜，从没听过哪怕一句夸奖，我还以为你们根本吃不出饭菜与干草的区别。”
- **婚姻外交手腕 (Marital Diplomacy)**: 桃乐赛·迪克斯名言：“不会甜言蜜语的别结婚。结婚前赞美是水到渠成，结婚后持续赞美则是必须履行的天职；婚姻不仅需要诚实，更需要精湛的外交艺术。”

## Mental Models
- **Appreciation as Daily Spiritual Oxygen**: 赞美不是节日限定的昂贵蛋糕，而是家庭日常呼吸所不可或缺的氧气。
- **The Best-Dressed Compliment**: 夸赞太太去年的衣服依然典雅动人，往往比任何昂贵的巴黎定制新装更能让女性心满意足。

## Anti-patterns
- **理所当然的冷漠沉默 (Taking Efforts for Granted)**: 顿顿吃着香甜可口的饭菜却从不吭声，视若空气，仿佛家里有一台自动运转的机器人。
- **吝于赞美而奢靡补偿 (Overspending to Compensate Silence)**: 宁可在吵架后花几万块买珠宝钻石消灾，也吝啬在清晨给予一个真诚的亲吻与赞美。

## Worked Example
好莱坞是一个婚姻破碎率极高、甚至连伦敦劳合社都不敢承保婚姻险的浮华名利场。然而著名电影巨星巴克斯特夫妇却在此构筑了历久弥新的模范美满婚姻。巴克斯特夫人原名蓓蕾荪，曾是一位极有前途的知名舞台剧台柱，婚后毅然放弃了掌声如雷的舞台事业洗尽铅华回归家庭。外界普遍认为这是一种痛苦的牺牲，但巴克斯特夫人却始终洋溢着幸福的笑容。巴克斯特先生在接受杂志专访时道出了其中的真谛：“她虽然失去了舞台上成千上万陌生人的掌声与赞美，但在家庭中，我随时随地都在她的身旁，她时刻都能听到我出自心底最深处的由衷赞赏与钦佩。如果一个妻子渴望从丈夫身上获得幸福与欢愉，她完全可以从丈夫真诚的热爱与欣赏中汲取无尽的源泉。而真诚的赞美她，也正是我毕生最大的快乐。”

## Key Takeaways
1. 男士们往往记不得五年前自己穿什么衣服，但女人对衣服与细节的记忆刻骨铭心；多留心并由衷赞扬女性的仪态与装扮。
2. 著名喜剧明星埃迪·坎特多次在公开访谈中直言：“全世界所有人中，我太太对我的帮助最大，我如果有任何微小的成就，完全归功于我的太太。”
3. 赞赏能让疲惫的主妇容光焕发，让枯萎的青春重现生机。
4. 保持家庭美满快乐的第四项法则：给予真诚的欣赏。
